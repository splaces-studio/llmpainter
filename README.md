# llmpainter

«Рисовалка» — простой холст для скетчей, чтобы объяснять идеи LLM рисунком, а не словами.

Вы рисуете схему, сохраняете её как PNG или копируете текстовое описание (координаты линий и подписи) и отправляете в чат.

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | Сам холст. Одна страница без зависимостей — откройте в браузере. |
| `risovalka-skill.md` | Навык для любой LLM: инструкция и полный код холста в одном файле. |
| `claude-skill/risovalka/` | Вариант для Claude Code: навык, который показывает холст прямо в чате. |

## Как пользоваться

**Без LLM.** Скачайте `index.html` и откройте в браузере.

**С любой LLM.** Отправьте модели файл `risovalka-skill.md` и попросите запомнить. Дальше пишите «рисовалка» или «надо скетч нарисовать». Надёжнее положить файл в инструкции проекта: память моделей обычно не вмещает код целиком.

**С Claude Code.** Скопируйте папку `claude-skill/risovalka` в `~/.claude/skills/`. В новом чате напишите «рисовалка» или `/risovalka`.

## Инструменты холста

Карандаш, прямая линия, рамка, текстовые подписи, пять цветов, толщина линии, сетка, отмена, очистка, сохранение в PNG, копирование описания скетча.

## Ограничение

Модель не видит холст напрямую. Чтобы показать рисунок, прикрепите PNG или вставьте скопированное описание.
